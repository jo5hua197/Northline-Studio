# Northline Studio — Landing Page

Landing page desarrollada con **HTML y CSS** para la materia de Programación de
Sistemas Web (examen de maquetación, propuesta *Northline Studio*).

Agencia creativa ficticia. Diseño basado en la referencia y la guía visual
(`design.md`) del ejercicio.

## Secciones

- Header con logo, navegación y CTA.
- Hero editorial con imagen de fondo.
- "Lo que hacemos" — 3 tarjetas de servicios.
- Proyecto destacado (TerraCo).
- Testimonio.
- Newsletter.
- Footer.

## Técnicas usadas

- HTML semántico (`header`, `nav`, `main`, `section`, `footer`).
- Layout con **Flexbox** y **CSS Grid** (footer).
- Tipografías con **Google Fonts** (Cormorant Garamond + Manrope).
- Imágenes de fondo con `background-size: cover`.
- Diseño **responsivo** con media queries.

## Estructura

```
northline-studio/

```

## Cómo verla

Abre `index.html` en el navegador, o usa la extensión **Live Server** de VS Code.
